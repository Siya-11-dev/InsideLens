# InsideLens — Pitch Outline

Place your final pitch deck (PDF/PPTX) in this folder as `docs/pitch.pdf` (or `docs/pitch.pptx`) and link it from the README.

## Suggested 5-minute flow
1. Problem (30s): match tools say what, not why; black-box; one-size-fits-all.
2. Solution (45s): InsideLens turns synthetic events into explainable intelligence.
3. Demo (120s): live pitch (MUN vs MCI), insight card with factors/evidence/counterfactual, patterns, highlights, recap in 2 languages, persona switch.
4. Architecture & Azure (60s): Event Hubs → FastAPI → Foundry/Translator/SQL/Fabric; offline fallback.
5. Differentiation & impact (45s): 28-col dataset export, eval harness, tests, open source.
6. Ask (20s): judges' feedback, pilot with a broadcaster.
